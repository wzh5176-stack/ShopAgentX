# 商品知识资料

本目录当前包含36份逐型号的虚构商品说明书及保留的独立K1教学说明书。只加载`catalog.json`列出的资料，不递归扫描README或任意用户路径。

稳定资料key用于片段归属，不等同MySQL商品ID。Java从真实在售商品读取名称和品牌，Python精确匹配目录，再在该型号内向量检索。价格与库存请查业务接口。

本批数据统一由根目录`scripts/build_demo_catalog.py`生成。修改生成源并升级版本后重建；生成器会覆盖生成的目录清单、MD和SVG。数据库导入单独执行，不随HTTP服务启动自动运行，也不覆盖既有商品/库存。

完整维护方式、接口和验收边界见[商品资料与RAG](../../docs/CATALOG_RAG.md)。
