# ShopAgent 开发路线

目标：完成并理解一个可演示的 Java + Python AI 导购与交易学习项目，简历描述以实际实现和验收为依据。

## 已完成主线

1. Spring Boot商品CRUD、逻辑删除、统一异常与管理端保护。
2. 普通用户注册、登录、本人数据隔离和CSRF。
3. Python/FastAPI对接DeepSeek，需求解析、预算筛选与可信商品推荐。
4. 多轮上下文、SSE流式回答、会话历史、商品资料检索与知识问答。
5. 购物车及自然语言待确认操作，执行前由用户明确确认。
6. 跳糖选物商城、商品浏览、导购台、购物车和资料问答网页。
7. Redis共享会话、Nginx双Java实例、Docker/Linux部署；独立RedisCluster故障切换及数据库备份恢复演练。
8. 收货地址、服务端可信核价、库存预占、幂等下单、本人订单列表/详情、取消与超时回收。
9. 本地模拟支付、支付宝官方沙箱入口、通知验签、查单补偿及关单协调。
10. 地址、结算、订单及支付页面；交易版Linux增量部署与集中验收。

## 当前证据边界

本机真实沙箱付款通知、漏通知查单补偿、未建官方交易的过期回收、普通取消已验证。Linux已验证原库恢复与数据保留、双实例共享登录、交易API、真实AI/RAG、网页及官方只读查单和公网通知拒绝无签名请求。

真实WAIT_BUYER_PAY交易主动官方关单仍未实测；Linux没有代用户新付款。最终Pinggy冷重连/停机脚本只做语法检查。独立RedisCluster演练不等于网站已接入Cluster；30次串行商品查询不代表最大QPS或高并发能力。
