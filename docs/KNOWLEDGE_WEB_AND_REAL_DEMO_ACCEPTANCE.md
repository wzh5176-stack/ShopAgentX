## 页面怎样用

打开 http://127.0.0.1:8888/shopagent/knowledge.html ，输入问题后点击“查资料，找答案”。示例按钮只填草稿，不自动消耗模型请求。网页显示回答、是否有依据、可展开的引用原文和来源信息。失败时保留问题，不自动重试。

当前资料仅有虚构《演示耳机K1使用说明》，不对应商城在售商品。页面明确展示演示属性；知识问答是单次查询，不保存到私人导购会话。真实商品的预算筛选和购物车仍从AI导购入口进行。

请求路径：网页 → Java `POST /api/assistant/knowledge` → Python检索本地资料片段 → DeepSeek依据片段回答 → Java复核回答与引用结构 → 网页安全显示原文。资料不足时没有引用，也不填猜测参数。
